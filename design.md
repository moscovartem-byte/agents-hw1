# Данные и расчеты

## Организация
Итоговый файл: tracker-v2.html.
Разметка, CSS и JavaScript находятся внутри файла.
Внешние зависимости и сетевые обращения не требуются.

## Модель задачи
| Поле | Тип | Ограничения |
|---|---|---|
| id | string | Уникальный идентификатор |
| title | string | Непустая строка после trim |
| hours | number | От 0,5 до 24 включительно, кратно 0,5 |
| done | boolean | Состояние выполнения |

Задачи хранятся в списке.
Добавление изменяет этот список.
Удаление и переключение done выполняются по id.

## Начальное состояние
| title | hours | done |
|---|---:|---|
| Чтение | 2 | true |
| Практика | 4 | false |
| Повторение | 2 | false |

Начальный фильтр — «все».

## Проверка формы
1. Получить исходные значения полей.
2. Проверить название после trim.
3. Проверить часы на пустое значение до числового преобразования.
4. Проверить числовое значение на конечность.
5. Проверить диапазон 0,5–24 включительно.
6. Проверить кратность 0,5.
7. При ошибках показать сообщения рядом с полями,
   сохранив значения формы и исходные данные задач.
8. При корректном вводе добавить задачу с done=false.

Шаг поля часов — 0,5.
Проверка данных должна обеспечивать это ограничение
и при ручном вводе.

## Расчеты
T — сумма hours всех задач.
D — сумма hours задач, у которых done=true.

Показатели:
- всего часов: T;
- выполнено часов: D;
- прогресс: 0%, если T=0;
- иначе прогресс: round(100 × D / T).

Проверочные значения:
| Состояние | T | D | Прогресс |
|---|---:|---:|---:|
| Начальный пример | 8 | 2 | 25% |
| Практика завершена | 8 | 6 | 75% |
| Все задачи удалены | 0 | 0 | 0% |

## Фильтрация
| Фильтр | Видимые задачи |
|---|---|
| Все | Все задачи |
| Активные | done=false |
| Готовые | done=true |

Показатели вычисляются по исходному списку,
до применения фильтра.

После добавления, удаления или переключения done
обновляются данные, показатели и видимый список.
Смена фильтра меняет только видимый список.

## Интерфейс
- Подписанные поля названия и часов.
- Ошибки непосредственно рядом с соответствующими полями.
- Подписанная кнопка добавления.
- Общие часы, выполненные часы и процент прогресса.
- Фильтры «все / активные / готовые».
- Для каждой задачи: название, часы,
  отметка «готово» и подписанная кнопка удаления.

На ширине 390 px элементы переносятся или располагаются
вертикально. Длинные названия переносятся внутри доступной
ширины и не создают горизонтальный скролл.

## Необязательное сохранение
При реализации localStorage:
- начальный пример используется при отсутствии сохраненных данных;
- сохраненный пустой список не заменяется примером;
- после изменения задач сохраняется их актуальный список;
- ошибки чтения или записи перехватываются;
- при ошибке показывается понятное сообщение;
- работа продолжается в памяти.
