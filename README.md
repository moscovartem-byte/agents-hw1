# agents-hw1
ДЗ1 — два способа разработки мини-трекера

Работа по факультативу «Создание ИИ-агентов с нуля», **вариант A (Новичок)**. Сравниваются два способа создания мини-трекера учебных задач с помощью **GPT-6.1 Sol**:

- **Direct (v1)** — реализация по короткому прямому запросу.
- **Spec (v2)** — подготовка спецификации, затем реализация по ней. Использована спецификация в формате OpenSpec, без CLI.

Трекер позволяет добавлять и удалять задачи, отмечать выполнение, фильтровать список и просматривать суммарные часы и прогресс.

Запуск

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив либо скачайте отдельно HTML-файлы.
2. Откройте `tracker-v1.html` или `tracker-v2.html` двойным щелчком в обычном браузере.

Установка библиотек, сборка и запуск сервера не требуются: каждый HTML-файл содержит стили и JavaScript. Страница HTML-файла на GitHub показывает исходный код; для запуска скачайте файл и откройте его локально.
