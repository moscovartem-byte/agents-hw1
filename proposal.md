# Мини-трекер учебных задач на неделю

## Цель
Создать автономный мини-трекер учебных задач на неделю
с добавлением, удалением, отметкой выполнения и учетом
прогресса по часам.

## Результат
Один файл tracker-v2.html со встроенными CSS и JavaScript.
Работа в обычном браузере без CDN, внешних библиотек,
внешних ресурсов и API-ключей.

## Границы
- Данные задачи: id, title, hours, done.
- Добавление, удаление и переключение done меняют данные.
- Проверка названия и оценки времени.
- Фильтры «все / активные / готовые».
- Общие часы, выполненные часы и прогресс по часам.
- Читаемый интерфейс на ширине 390 px без горизонтального скролла.
- Подписанные поля и кнопки.

Начальный пример:
| Название | Часы | done |
|---|---:|---|
| Чтение | 2 | true |
| Практика | 4 | false |
| Повторение | 2 | false |

Начальные показатели: всего 8 ч, выполнено 2 ч, прогресс 25%.

## Необязательное улучшение
Сохранение задач в localStorage.
При недоступности хранилища — понятное сообщение
и продолжение работы в памяти.

## Вне границ
Сервер, аккаунты, синхронизация, календарь,
автоматическая смена недели и другие функции,
не перечисленные в требованиях.

## Этапы
Этот запрос подготавливает только документы.
Реализация выполняется отдельным запросом.
